# India Data Dashboard

A modern, interactive web dashboard to explore **India District Crime Data** and **Election Results 2024** in one place. Built with **HTML, CSS, and JavaScript**, featuring clickable cards, emoji-based icons, and dynamic iframe content display.

---

## Features

- **India District Crime** – visualize crime data by district. 👮  
- **Election Results 2024** – explore constituency-wise election results. 🗳️  
- **Interactive Cards** – hover effects and clickable icons for an engaging UI.  
- **Dynamic Iframe Content** – open pages without leaving the dashboard.  
- **Close Button** – hide loaded content and return to homepage.  
- Fully responsive and mobile-friendly layout.  
- Lightweight design using **emoji icons** instead of images.
